## Output Format
- Describe the revised plan, emit the plan as a single fenced JSON block matching the schema below. Do not omit fields or add extra fields.
- Number the steps with `step_number`, starting at 1 and increasing by 1 with no gaps (1, 2, 3, …) in execution order.
- If you used or adapted one or more templates, list their snake_case names in `template_names` and explain in `justification` how each was used or adapted.
- If you wrote the plan from scratch with no template, set `template_names` to `[]` and explain in `justification` why no template applied.

```json
{
  "user_request": "<1-2 sentence paraphrase of the user's request>",
  "steps": [
    {
      "step_number": 1,
      "title": "<short imperative phrase, ≤8 words>",
      "description": "<1-3 sentence concrete description of what this step does>",
      "reasoning": "<why this step is needed — an explanation, not a restatement of description>",
      "expected_artifacts": ["<file path>", "..."]
    }
  ],
  "provenance": {
    "template_names": ["<snake_case template name>", "..."],
    "justification": "<free-form description of how each template was used or adapted, or why no template applied>"
  }
}
```
