## Findings

- All three benchmark runs were valid with perfect agreement to the expert reference, so the core scripted pipeline/order is already correct.
- Token use remained high (168k–192k) despite no replans. Trace inspection showed executors often listed/read skill directories and full script contents, inspected output heads/logs, and in some runs attempted ad-hoc verification. These extra tool calls inflated tokens and caused harmless errors such as `workspace/project/...` path failures and a pandas set-indexer error in custom verification code.
