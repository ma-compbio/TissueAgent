Abstract

From open-ended request to an auditable analysis.

Spatial transcriptomics analysis demands more than code generation: it requires biological judgment, tool selection, iterative quality control, and clear provenance across a heterogeneous workflow. TissueAgent turns natural-language requests and multimodal inputs—including datasets, papers, and figures—into runnable, inspectable analyses.

A shared evolving plan coordinates specialized agents for planning, recruitment, execution, evaluation, and reporting. Every step records its rationale, status, and artifacts, enabling targeted replanning when assumptions fail while preserving a coherent trail from question to result. The framework supports tasks spanning figure recreation, cell annotation, cell–cell communication, differential expression, and deconvolution.
